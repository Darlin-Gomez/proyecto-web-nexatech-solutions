# NexaTech Solutions — Proyecto internacional de contenido web

Página web ficticia de una empresa tecnológica internacional, creada como proyecto de portfolio personal para una trayectoria profesional como redactor de contenidos asociado (junior).

## Objetivo del proyecto

Demostrar habilidades prácticas en contenido web estructurado, HTML5 semántico, fundamentos de CSS, diseño adaptativo, accesibilidad y SEO básico.

## Habilidades demostradas

- HTML5 semántico
- Fundamentos de CSS3
- Diseño adaptativo
- Navegación accesible y enlaces descriptivos
- Contenido web corporativo estructurado
- Metadatos básicos de SEO
- Organización de proyectos con Git/GitHub

## Archivos del proyecto

- `index.html`: estructura de la página y contenido web
- `styles.css`: maquetación y presentación visual

## Estado del proyecto

Proyecto de portafolio personal. NexaTech Solutions es una empresa ficticia creada con fines demostrativos.
